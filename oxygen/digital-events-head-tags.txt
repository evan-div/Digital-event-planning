── NOTES ─────────────────────────────────────────────────────────────

- The Code Block content lives in digital-events-oxygen.php. Paste the
  entire file contents into the Oxygen Code Block on this page.
- Site header, primary nav, and footer are not included in the code block;
  they come from the theme as on every other page.
- CSS is scoped under the .ite-de wrapper class (matching the .ite-cs
  convention already used on case study pages) so it won't bleed into the
  rest of the site. #ite-scroll-progress and #cta-section/#cta-overlay are
  the only IDs used; renamed with an ite- prefix where there's any risk of
  colliding with another block on the same page.
- AvantGarde-Medium (500) and AvantGarde-Bold (700) are embedded directly
  in the <style> block as base64 WOFF2, so no external font requests are
  made. The Book/Demi weights are not included: those files are known to
  fail CFF parsing in the browser (confirmed by testing), so body copy and
  the few 600-weight labels nearest-weight-match to Medium/Bold instead.
